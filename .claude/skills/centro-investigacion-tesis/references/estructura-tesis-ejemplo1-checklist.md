## Estructura base de tesis

### Preliminares

- [ ] Portada institucional.
- [ ] Título de tesis.
- [ ] Autor.
- [ ] Asesor y coasesor, si corresponde.
- [ ] Grado o título al que se opta.
- [ ] Lugar y año.
- [ ] Dedicatoria.
- [ ] Agradecimientos.
- [ ] Índice general.
- [ ] Índice de tablas.
- [ ] Índice de figuras.
- [ ] Glosario de siglas y abreviaturas.
- [ ] Resumen en español.
- [ ] Palabras clave.
- [ ] Abstract en inglés.
- [ ] Keywords.
- [ ] Resumen en lengua originaria si la universidad lo exige.

### Introducción

- [ ] Contextualiza el problema.
- [ ] Presenta la necesidad de la investigación.
- [ ] Menciona el propósito del estudio.
- [ ] Resume la estructura de la tesis sin extenderse demasiado.

### Capítulo I: Problema de investigación

- [ ] Descripción del problema.
- [ ] Formulación del problema general.
- [ ] Formulación de problemas específicos.
- [ ] Objetivo general.
- [ ] Objetivos específicos.
- [ ] Justificación teórica, práctica, metodológica o tecnológica.
- [ ] Limitaciones delimitadas y reales.

Criterios de aprobación:

- El problema general deriva de la descripción del problema.
- El objetivo general responde al problema general.
- Los objetivos específicos responden a los problemas específicos.
- La justificación explica aporte, necesidad y utilidad.
- Las limitaciones no contradicen el alcance del estudio.

### Capítulo II: Antecedentes

- [ ] Antecedentes internacionales.
- [ ] Antecedentes nacionales.
- [ ] Antecedentes locales si corresponde.
- [ ] Síntesis crítica de estudios previos.
- [ ] Relación explícita con la tesis actual.

Criterios de aprobación:

- Los antecedentes son recientes y pertinentes.
- Cada antecedente incluye autor, año, objetivo, método, resultados y aporte.
- No es solo una lista; debe haber comparación crítica.
- La brecha de investigación queda clara.

### Capítulo III: Marco teórico

- [ ] Conceptos centrales del dominio.
- [ ] Fundamentos técnicos.
- [ ] Modelos, teorías o enfoques relevantes.
- [ ] Definición de métricas, variables o categorías usadas.
- [ ] Relación entre teoría y metodología.

Para este proyecto debe considerar:

- papas nativas y variedades del estudio;
- visión por computadora;
- clasificación de imágenes;
- redes neuronales convolucionales;
- EfficientNetB0 o CNN usada;
- Swin Transformer;
- aprendizaje por transferencia si aplica;
- métricas de clasificación: accuracy, precision, recall, F1-score, matriz de confusión.

### Capítulo IV: Metodología

- [ ] Enfoque de investigación.
- [ ] Tipo de investigación.
- [ ] Nivel de investigación.
- [ ] Diseño de investigación.
- [ ] Población.
- [ ] Muestra.
- [ ] Muestreo o criterios de selección.
- [ ] Técnicas e instrumentos.
- [ ] Procedimiento por etapas.
- [ ] Preprocesamiento de datos.
- [ ] Entrenamiento de modelos.
- [ ] Métricas de evaluación.
- [ ] Validez, confiabilidad o controles equivalentes.

Criterios de aprobación:

- El diseño metodológico permite cumplir los objetivos.
- La población y muestra están delimitadas.
- El procedimiento es reproducible.
- Las métricas corresponden al problema de clasificación.
- No se afirma causalidad si el diseño no la permite.

### Capítulo V: Resultados

- [ ] Descripción de la implementación.
- [ ] Presentación del dataset usado.
- [ ] Resultados del preprocesamiento.
- [ ] Resultados del entrenamiento.
- [ ] Métricas por modelo.
- [ ] Matrices de confusión.
- [ ] Comparación CNN vs Swin.
- [ ] Resultados por clase.
- [ ] Resultados por origen real/sintético si aplica.
- [ ] Interpretación de tablas y figuras.

Criterios de aprobación:

- Los resultados responden a los objetivos.
- Toda tabla o figura se interpreta en el texto.
- Las métricas se explican con cautela metodológica.
- No se concluye superioridad sin análisis suficiente.

### Capítulo VI: Discusión

- [ ] Interpretación de los hallazgos.
- [ ] Comparación con antecedentes.
- [ ] Explicación de coincidencias y diferencias.
- [ ] Alcances del estudio.
- [ ] Limitaciones metodológicas.
- [ ] Implicancias técnicas o académicas.

Criterios de aprobación:

- La discusión no repite resultados sin interpretarlos.
- Se contrasta con antecedentes reales.
- Se reconocen limitaciones.
- No se exagera la generalización.

### Conclusiones

- [ ] Conclusión vinculada al objetivo general.
- [ ] Conclusiones vinculadas a objetivos específicos.
- [ ] Resultados concretos citados sin exageración.
- [ ] No se agregan datos nuevos.

### Recomendaciones

- [ ] Recomendaciones derivadas de resultados.
- [ ] Recomendaciones derivadas de limitaciones.
- [ ] Propuestas para trabajos futuros.

### Referencias

- [ ] Toda cita aparece en referencias.
- [ ] Toda referencia fue citada.
- [ ] Formato APA 7 consistente.
- [ ] DOI o URL cuando corresponda.
- [ ] Autores y años coinciden.

### Anexos

- [ ] Código fuente o enlace verificable.
- [ ] Dataset o evidencia de disponibilidad.
- [ ] Instrumentos si aplica.
- [ ] Validaciones, permisos o cartas si aplica.
- [ ] Evidencias de resultados o capturas necesarias.

## Control final de coherencia

- [ ] Problema ↔ objetivo general.
- [ ] Problemas específicos ↔ objetivos específicos.
- [ ] Objetivos ↔ metodología.
- [ ] Metodología ↔ resultados.
- [ ] Resultados ↔ discusión.
- [ ] Resultados ↔ conclusiones.
- [ ] Limitaciones ↔ recomendaciones.
